# Homelab Documentation

Dokumentation des privaten Homelabs mit Schwerpunkt auf Proxmox, Debian-Monitoring, Tailscale und der Wiederverwendung alter Hardware.

## Systeme

| System | Funktion | Status |
|---|---|---|
| iMac5,1 | Lightweight Debian Server / Statusanzeige | In Entwicklung |
| Proxmox `pve` | Virtualisierung / Container / Docker | Produktiv |
| Debian Monitoring Server | Monitoring, Homepage und zentrale Dienste | Produktiv |

## Dokumentationsprinzip

- **bestätigt**: Zustand wurde im Projektverlauf geprüft oder dokumentiert
- **geplant**: gewünschter, noch nicht vollständig umgesetzter Zustand
- **prüfen**: Angabe aus einem früheren Stand; vor Änderungen erneut verifizieren
