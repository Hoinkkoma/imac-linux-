# Debian Monitoring Server

## Dokumentierter Tailscale-Stand

Die konkrete Tailscale-Adresse wird nicht öffentlich in diesem Repository dokumentiert.

Dieser Host ist die zentrale Monitoring-/Management-Maschine. Dokumentierte Dienste: Homepage, Grafana, Prometheus, Loki, Uptime Kuma, Scrutiny, Netdata, Pi-hole und Node Exporter.

## Homepage

- Projekt: `/opt/homepage`
- Container: `gethomepage/homepage:v2.1.2`
- Dashboard-Port: `3000`

Der iMac soll später Teile dieser Informationen für **DIE SCHWARZE TAFEL** abrufen. Private Netzwerkdaten und Zugangsdaten bleiben außerhalb des öffentlichen Dokumentationsstands.
