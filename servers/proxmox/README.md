# Proxmox `pve`

## Dokumentierter Stand

| Parameter | Wert |
|---|---|
| Hostname | `pve` |
| LAN-Adresse | nicht öffentlich dokumentieren |
| Gateway | nicht öffentlich dokumentieren |
| Tailscale-Adresse | nicht öffentlich dokumentieren |
| CPU | Intel Core i7-4770 |
| RAM | 31 GiB |

## Rolle

Proxmox ist die zentrale Virtualisierungs-, Container- und Docker-Plattform. Dokumentierte Dienste umfassen Docker, Ollama, Open WebUI, Grafana, Prometheus, Loki, Jellyfin, Vaultwarden, Portainer und Chatwoot.

Vor einer Aktualisierung mit `pct list`, `qm list` und Docker-Kommandos verifizieren. Netzwerk- und Tailscale-Adressen gehören in eine lokale, nicht öffentliche Notiz.
